Green Plate Value Engine

June 2026 · Python, Streamlit, Google Places API, scikit-learn, PyDeck

A web app for finding vegetarian-friendly restaurants. Enter a location and it pulls nearby restaurants from the Google Places API, then ranks them with a value score that combines each restaurant's Google rating with plant-based keywords found in its reviews and editorial summaries.

  • Interactive map with color-coded restaurant pins
  • Neighborhood summaries showing typical prices and top picks
  • Isolation Forest anomaly detection that flags suspicious listings, like very high ratings with very few reviews
  • Results you can sort by value score, rating, number of reviews, or price

Are Explicit Tracks More Popular?

March 2026 · Python, Pandas, scikit-learn, Statistical Testing

An analysis of 5,505 Spotify tracks across five genres, testing whether explicit songs are more popular than non-explicit ones. The project starts with a hypothesis test to see if the popularity gap is real or just chance, then builds a machine learning model that predicts a track's popularity from its features. Finally, it checks whether that model works equally well for explicit and non-explicit songs, or whether it is biased toward one group.

  • A permutation test found explicit tracks score 5.06 points higher in popularity on average (p < 0.001)
  • A Random Forest model predicting popularity reached an F1-score of 0.421, up from 0.332 for the baseline
  • A fairness check found the model was much more precise for explicit tracks (0.562) than non-explicit ones (0.301)

Traveler Insight CLI

Python, DSPy, OpenAI API (gpt-4o-mini), Wikipedia API

A command-line tool that helps travelers get to know a destination before they go. You type in a place, and it pulls live Wikipedia articles about it, then uses an LLM to turn them into a short cultural briefing.

  • Each briefing has seven sections: cultural etiquette, language and communication, food and dining norms, festivals and holidays, religion and spiritual sites, heritage and monuments, and conversation starters
  • Uses DSPy to structure the LLM prompts, so every briefing follows the same format
  • Handles ambiguous place names by detecting when a search matches multiple Wikipedia articles
  • Lets you look up multiple destinations in one session
